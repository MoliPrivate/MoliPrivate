## INSTALLAZIONE

![Divider](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

</div>

### Prerequisiti

Prima di installare questo capolavoro, assicurati di avere:

- [ ] Node.js (versione 18+ o la tua versione preferita, non giudichiamo)
- [ ] npm o yarn o pnpm o bun o il tuo gestore di pacchetti preferito
- [ ] Git (ovviamente)
- [ ] Un computer
- [ ] Una tastiera
- [ ] Un mouse (opzionale, ma consigliato)
- [ ] Caffè (obbligatorio)
- [ ] Pazienza (illimitata)
- [ ] Un gatto (opzionale ma aumenta il successo del 42%)
- [ ] Un'anima (a meno che non siate vampiri)
- [ ] WiFi (o Ethernet, non siamo esigenti)
- [ ] Un cervello funzionante (a volte opzionale)

### Linux / macOS

```bash
# Clona il repository (con stile)
git clone https://github.com/tuoutente/github-alt.git

# Entra nella cartella (con eleganza)
cd github-alt

# Installa le dipendenze (con speranza)
npm install

# Avvia il progetto (con paura)
npm run dev
```

### Windows

```powershell
# Clona il repository
git clone https://github.com/tuoutente/github-alt.git

# Entra nella cartella
cd github-alt

# Installa le dipendenze
npm install

# Se fallisce, riprova (funziona il 50% delle volte)
npm install --force

# Se fallisce ancora, prega
echo "Signore, dammi la forza"

# Avvia il progetto
npm run dev
```

### Docker (per i veri professionisti)

```bash
docker build -t github-alt .
docker run -p 3000:3000 github-alt
```

### Se tutto fallisce

```bash
# Formatta il PC
rm -rf /

# Compra un nuovo computer
# Installa tutto da capo
# Piangi un po'
# Funziona
```

Vuoi contribuire? **OTTIMO!** Siamo disperati. Abbiamo bisogno di te. Sì, proprio di te. No, non sto scherzando.

### Come contribuire:

1. Fai un fork del progetto
2. Crea un branch (`git checkout -b feature/nuova-feature-incredibile`)
3. Fai commit (`git commit -m "feat: aggiunta feature che cambierà il mondo"`)
4. Pusha (`git push origin feature/nuova-feature-incredibile`)
5. Apri una Pull Request
6. Aspetta (potrebbe volerci un po')
7. Se tutto va bene, festeggia!

### Regole per contribuire:

- Scrivi codice pulito (o almeno non troppo sporco)
- Commenta il codice (in italiano, grazie)
- Segui lo stile del progetto (se lo trovi, faccelo sapere)
- Testa il codice (almeno una volta)
- Non rompere niente (per favore)
- Non aggiungere feature che non servono (a meno che non siano divertenti)
- Non lasciare TODO in giro (o almeno metti una data)
